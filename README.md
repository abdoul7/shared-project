# Shared Project

A starter project for collaborating with GitHub and Codex.

## Working together

1. Clone this repository and open the folder in Codex.
2. Pull the latest changes before starting work.
3. Create a branch for your task: `git switch -c your-name/task-name`.
4. Commit and push your changes, then open a pull request.
5. Review and merge changes together.

Agree on the first feature before adding application code.
